| [capstone](capstone/README.md) | One Northwind feature taken through pm, designer, data-scientist and accountant |

Shared data for every track is in `_data/northwind/`.

Answer keys (`SOLUTION.md`, `checks/expected*`, `_data/northwind/answer_key.json`) are hidden from the AI via `.cursorignore`; instructors open them directly.
