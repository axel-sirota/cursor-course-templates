# ECS Service Domain Example: Providers & Version Pinning Template

Provider/version pinning and backend configuration for the ECS Fargate + ALB worked example — the Terraform analog of the reference stack's `requirements.txt`.

## Root `providers.tf`

```hcl
terraform {
  required_version = ">= 1.9, < 2.0.0"

  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}

provider "aws" {
  region = var.aws_region

  default_tags {
    tags = {
      Project     = var.project
      Environment = var.environment
      ManagedBy   = "terraform"
    }
  }
}
```

## Per-Module `versions.tf`

Every module under `modules/` declares its own `versions.tf` so it can be sourced independently (e.g. from a module registry) with an explicit, self-documented provider constraint:

```hcl
# modules/vpc/versions.tf
terraform {
  required_version = ">= 1.9"
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}
```


## `.terraform.lock.hcl`

Generated by `terraform init` and **committed** (not gitignored) — it pins exact provider checksums for reproducible plans across every contributor and CI run. Regenerate deliberately with `terraform init -upgrade` when bumping a provider version, and review the diff.
