# Designer React + Tokens Starter

Use these patterns when `/architect` scaffolds the Phase 0 skeleton. The full working version is in `examples/budget-card/`. Copy from there when in doubt.

## Phase 0 deliverables
| File | What it holds |
|---|---|
| `tokens/tokens.json` | `primitive` + `semantic` layers, at least color, space, font, radius |
| `scripts/build-tokens.mjs` | copy from `examples/budget-card/scripts/` unchanged |
| `src/styles/tokens.css` | generated by `npm run build:tokens` |
| `src/components/<Name>.tsx` | one file per component in the inventory, rendering a placeholder |
| `src/components/<Name>.stories.tsx` | one story per component |
| `src/components/<Name>.test.tsx` | render + axe test per component |
| `src/tokens.test.ts` | runs the token check |
| `plans/interface-contract.md` | token set, component inventory, screen layout |

## package.json scripts
```json
{
  "scripts": {
    "build:tokens": "node scripts/build-tokens.mjs",
    "check:tokens": "node scripts/build-tokens.mjs --check",
    "test": "npm run build:tokens && vitest run",
    "typecheck": "tsc --noEmit",
    "storybook": "npm run build:tokens && storybook dev -p 6006"
  }
}
```
Pinned devDependencies are listed in `examples/budget-card/package.json`.

## Minimal tokens.json
```json
{
  "primitive": {
    "color": { "slate": { "900": { "$value": "#1e293b", "$type": "color" } } },
    "space": { "4": { "$value": "16px", "$type": "dimension" } }
  },
  "semantic": {
    "color": { "text": { "default": { "$value": "{primitive.color.slate.900}", "$type": "color" } } },
    "space": { "inset": { "md": { "$value": "{primitive.space.4}", "$type": "dimension" } } }
  }
}
```

## Placeholder component
```tsx
import './CategoryRow.css';

export type CategoryRowProps = { label: string };

export function CategoryRow({ label }: CategoryRowProps) {
  return <div className="category-row">{label}</div>;
}
```
```css
.category-row { padding: var(--space-inset-md); color: var(--color-text-default); }
```
